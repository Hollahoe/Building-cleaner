# 건물주 인터뷰 가이드

## 목적

**팔지 말고 듣기만 합니다.** 10명의 답변이 그대로 사업 아이템 리스트가 됩니다.
인터뷰 중에 해결책이나 가격을 말하는 순간, 상대는 진짜 고통 대신 예의상 하는 말을 하기 시작합니다.

## 대상

- 소규모 건물(꼬마빌딩, 상가주택, 원룸·다가구, 소형 상가)을 **직접 관리하는** 건물주
- 관리를 맡겼다가 직접 하기로 바꾼 분, 반대로 직접 하다가 맡긴 분도 좋습니다. 둘 다 이유를 들을 수 있습니다.
- 후보 리스트: [`candidates.csv`](candidates.csv)
- 섭외 경로: 멘토님, 지인, 부모님 지인, 부동산 카페, 상가 번영회 → 문구는 [카톡 템플릿](../ops/kakao-templates.md)

## 진행 (30분)

| 시간 | 할 일 |
|---|---|
| 0–3분 | 감사 인사. "제가 뭘 팔려는 게 아니라, 건물 관리하시면서 뭐가 제일 힘드신지 배우려고 왔습니다." 녹음은 동의를 받은 경우에만 합니다. |
| 3–5분 | 건물 기본 정보: 유형, 대략적인 규모, 층수, 승강기 여부, 보유 기간, 직접 관리하는지 여부 |
| 5–25분 | **고정 질문 5개**(아래). 질문마다 꼬리 질문으로 최근 사례와 금액을 끌어냅니다. |
| 25–30분 | 마무리: "건물관리 앱이나 관리 서비스를 써보신 적 있으세요?"(경쟁사 확인), 리포트 약속, 다른 건물주 소개 요청, (선택) 관리비 고지서나 업체 계약서 사진 공유 요청 |

## 고정 질문 5개

모든 인터뷰에서 **같은 순서, 같은 문장**으로 묻습니다. 그래야 10명을 비교할 수 있습니다.

### Q1. 관리하면서 제일 돈 아깝다고 느낀 게 뭐예요?
- 꼬리 질문: 그게 한 달에 얼마예요? / 마지막으로 그렇게 느낀 게 언제예요? / 왜 아깝다고 느끼셨어요(가격, 품질, 안 하는 것 같아서)?

### Q2. 제일 머리 아픈 민원이 뭐예요?
- 꼬리 질문: 가장 최근 민원 하나만 처음부터 끝까지 얘기해 주세요. / 해결하는 데 며칠 걸렸어요? / 누구한테 전화하셨어요? / 돈은 얼마 들었어요?

### Q3. 지금 관리비가 월 얼마예요? 어디에 제일 많이 나가요?
- 꼬리 질문: 고지서나 통장 내역 기준으로 항목을 나눠 주실 수 있어요? / 작년보다 올랐어요?
- 정확한 숫자를 모르셔도 괜찮습니다. "모른다"는 것 자체가 중요한 정보입니다.

### Q4. 청소, 승강기, 소방, 보험, 세무 중에 직접 알아보시는 게 있어요?
- 꼬리 질문: 업체는 어떻게 찾으셨어요? / 견적은 몇 군데 받아보셨어요? / 마지막으로 업체를 바꾼 게 언제예요? / 법정 점검 일정은 누가 챙겨요?

### Q5. 관리업체를 바꿀 생각이 있으세요? 왜요?
- 꼬리 질문: 바꾸려다 못 바꾼 적 있으세요? 왜 못 바꾸셨어요? / 누가 대신 다 알아봐 준다면 무엇을 맡기고 싶으세요? / 무엇은 절대 안 맡기고 싶으세요?

## 하지 말 것

- **유도 질문**: "청소비 너무 비싸시죠?" 대신 "청소는 어떻게 하고 계세요?"라고 묻습니다.
- **미래형 질문**: "이런 서비스 있으면 쓰시겠어요?"에는 대부분 "네"라고 답합니다. 대신 과거에 실제로 돈과 시간을 쓴 경험을 묻습니다.
- **해결책·가격 제시**: 인터뷰 중에는 하지 않습니다. 물어보시면 "정리해서 리포트로 보내드릴게요"라고 답합니다.
- **법률·세무 조언**: 세입자 분쟁이나 세금 질문을 받으면 "그건 전문가께 확인하시는 게 맞을 것 같아요"라고 답합니다([법률 체크리스트](../docs/legal-checklist.md)).

## 인터뷰 후 (당일 안에)

1. [`note-template.md`](note-template.md)를 복사해서 기록합니다. 기억이 흐려지기 전에 **들은 말을 그대로** 적습니다.
2. 엑셀 [`tools/savings-calculator.xlsx`](../tools/savings-calculator.xlsx)의 `고통집계` 시트에 한 줄을 입력합니다.
3. [`candidates.csv`](candidates.csv)의 상태를 `인터뷰완료`로 바꿉니다.
4. 감사 카톡을 보냅니다([템플릿 4번](../ops/kakao-templates.md#4-인터뷰-직후-감사-인사)).
