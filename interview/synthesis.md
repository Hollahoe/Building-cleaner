# 인터뷰 10건에서 고통 TOP 3 뽑는 법

## 1. 점수 매기기 (인터뷰마다)

[기록지](note-template.md) 맨 아래의 고통 점수를 엑셀 [`tools/savings-calculator.xlsx`](../tools/savings-calculator.xlsx)의 `고통집계` 시트에 한 줄씩 입력합니다.

| 점수 | 기준 | 예시 |
|---|---|---|
| 0 | 언급 없음 | |
| 1 | 언급만 함 | "청소도 좀 신경 쓰이고요" |
| 2 | 구체적 사례나 금액을 말함 | "청소비가 월 45만 원인데 계단이 늘 더러워요" |
| 3 | 돈이나 시간을 써서 해결하려고 시도한 적 있음 | "작년에 청소 업체를 두 번 바꿨어요" |

3점이 중요한 이유: **이미 돈이나 시간을 쓰고 있는 문제**라서, 더 나은 해결책이 있으면 바로 돈을 낼 가능성이 높습니다.

## 2. 순위 정하기

엑셀이 항목별로 자동 계산합니다.

1. **총점**이 높은 순
2. 총점이 같으면 **3점을 준 사람 수**가 많은 순
3. 그래도 같으면 Q3에서 나온 **월 금액**이 큰 순(직접 비교)

## 3. 결과 해석할 때 주의

- `[가설]` 조언의 예상은 "1위 청소, 2위 승강기·소방 유지보수, 3위 공실·임대관리"입니다.
  이 예상을 미리 적어두고, 실제 결과와 비교해서 **틀린 부분을 기록하세요.** 틀린 부분이 가장 큰 배움입니다.
- 10명 중 한두 명이 강하게 말한 것보다, **여러 명이 2점 이상을 준 항목**이 더 확실한 신호입니다.
- 공실·임대관리가 1위로 나와도, 운영자가 직접 할 수 있는 범위는 제한적입니다(임대차 중개는 공인중개사 영역, [법률 체크리스트 4번](../docs/legal-checklist.md#4-공실임대관리-공인중개사법-제48조)).
