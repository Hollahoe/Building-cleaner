# 브랜딩 전략 요약 (2026-11-10)

전체 문서는 Claude 문서 **[빌딩모아관리 36개월 실행계획](https://claude.ai/artifact/XLYXKuGHhTudfHkvk1GK3B#0daf2e16-dfc9)** 의 '브랜딩 전략' 탭에 있습니다.
경쟁 브랜드 지도, 브랜드 플랫폼, 접점 도해가 거기에 있습니다. 이 파일은 레포에서 바로 볼 수 있는 요약입니다.

> 상표 등록 여부는 확인하지 못했습니다. 특허청 검색 사이트(KIPRIS) 접속이 거부됐습니다.
> 이름을 확정하기 전에 KIPRIS 조회와 변리사 의견을 받아야 합니다.

## 한 줄 결론

브랜드의 약속을 "함께 사서 아낀다"에서 **"관리사무소 없는 건물의 관리사무소"** 로 바꿉니다.
브랜드는 광고로 만들지 않고, 건물주 손에 남는 증거물(의무 리포트, 가격표, 월간 기록, 현판)로 쌓습니다.

## 1. 진단: 지금 브랜드는 바뀐 전략과 어긋납니다

| 요소 | 지금 | 문제 |
|---|---|---|
| 이름 | 빌딩모아관리 | '모아'가 공동구매를 뜻합니다. '빌딩○○' 이름이 이미 많습니다(빌딩케어, 빌딩플러스, 빌딩솔루션, 빌사남, 빌즈, 빌라온) |
| 웹 첫 문장 | "건물 운영비, 이웃 건물과 함께 사면 내려갑니다" | 절감을 약속합니다. 묶음 할인 근거는 승강기 대수 할인뿐이라 지키기 어렵습니다 |
| 상품명 | 법정관리 라이트·스탠다드 | '법정관리'는 흔히 기업 회생절차를 가리키는 말입니다(검색 결과로 확인) |
| 증거물 | 수요 게시판, 무료 운영비 진단 | 공동구매가 전제입니다 |

아직 공개 배포 전이라 지금이 고치는 비용이 가장 낮습니다.

## 2. 고객과 경쟁

- **고객:** 관리사무소를 둘 수 없는 건물의 주인입니다.
  - 마포 '일반' 근생 대상은 2,866동이고, 연면적 중앙값은 595㎡입니다.
  - 2026년 상반기에 검사받은 695동 중 279동(40%)이 승강기 첫 검사에서 조건부합격이었습니다.
- **가설(인터뷰로 검증):** 건물주는 '싸게'보다 '빠뜨리지 않게, 얼마인지 미리 알게'에 반응합니다.
  - 알림은 소방청이 이미 무료로 보냅니다. 돈을 내는 이유는 처리와 기록입니다.
- **경쟁 브랜드:** '편리한 도구'(자리톡, 관리비책, 빌딩케어)나 '통합 관리'(둥지, 글로벌PMC, 하우스맨)를 내세웁니다.
  - '법정 의무 책임 + 정찰제 + 공개 기록'을 함께 내건 곳은 찾지 못했습니다(28곳 조사, 대부분 검색 결과만).

## 3. 브랜드 플랫폼

**포지셔닝 문장**

> 관리사무소를 둘 수 없는 꼬마빌딩 건물주에게, 빌딩모아는 법정 점검부터 청소와 관리비 정산까지 정해진 월 요금으로 책임지는 동네 관리사무소입니다.
> 견적제 관리업체와 달리 가격표와 관리 기록을 공개합니다.

| 기둥 | 실제로 만들 증거물 | 아직 안 된 것 |
|---|---|---|
| 빠뜨리지 않습니다 | 건물별 의무 달력, 점검 입회 기록, 승강기 안전관리자 선임 수임 | 안전관리자 수임과 '우리 잘못이면 보상' 약정은 변호사 검토 뒤에 약속합니다 |
| 가격이 정해져 있습니다 | 연면적 구간별 가격표 공개, 업체에서 수수료를 받지 않는 원칙 | 가격은 인터뷰 30명 뒤 확정합니다. 수수료 0 원칙은 결정이 필요합니다 |
| 기록으로 보여 드립니다 | 월간 관리 리포트, 항목별 관리비 내역서 | 내역서 자동 발행은 2단계입니다 |

**성격과 말투: 꼼꼼한 관리소장**

- 숫자와 날짜로 말합니다.
- 겁주지 않습니다.
- 쉬운 우리말을 씁니다.
- 계약서에 있는 것만 약속합니다.

정성 평가이고 제 판단입니다.

- **1안: 빌딩모아 + 설명어 '꼬마빌딩 책임관리'.** '모아'의 뜻을 '함께 산다'에서 '흩어진 관리를 한곳에 모은다'로 바꿔 씁니다.
- **2안: 빌딩지기.** 1안이 상표에서 막히거나, 인터뷰에서 '모아'가 여전히 공동구매로 읽히면 이쪽으로 갑니다.
- **이름 충돌:** 웹 검색에서 다섯 이름('빌딩모아', '빌딩모아관리', '빌딩지기', '건물지기', '모아관리') 모두 같은 이름의 건물관리 업체가 나오지 않았습니다(검색 결과만).
- **상표법(원문 확인):**
  - 제33조 제1항 제3호: 성질을 표시한 말만으로 된 상표는 등록할 수 없습니다.
  - 제34조 제1항 제7호: 먼저 등록된 비슷한 상표가 있으면 등록할 수 없습니다.
  - 제35조: 먼저 출원한 사람이 등록받습니다.

|---|---|
| 슬로건 | 관리사무소 없는 건물의 관리사무소 |
| 웹 첫 문장 | 꼬마빌딩 법정 점검, 빠뜨리지 않게 저희가 챙깁니다 |
| 웹 보조 문장 | 승강기·소방·전기·저수조 점검 일정부터 입회, 후속조치, 기록까지 맡습니다. 가격은 표에 있습니다 |
| 리포트 봉투 | ○○로 ○○ 건물의 승강기 검사 유효기간이 ○월에 끝납니다 |

- **쓸 수 있는 숫자:** 원자료 파일이 있는 것만 씁니다. 표시광고법 제5조는 사실에 관한 표시를 실증할 수 있어야 한다고 정합니다(원문 확인).

  - 경쟁사 이름을 넣은 비교, 승강기 업체 순위
  - 겁주는 말
  - 절감률 약속
  - 근거 없는 "공인"

## 6. 접점: 증거물 다섯 개

| 접점 | 무엇을 주나 | 재는 것 |
|---|---|---|
| 1. 건물 의무 리포트 | 건물 주소로 보내는 한 장(다음 승강기 검사 달, 지난 검사 결과, 소방 점검 달) | 응답률 |
| 2. 방문 진단 | 현장 확인과 가격표 한 장 | 방문 → 계약 전환율 |
| 3. 계약 | 계약서와 '책임 범위' 한 장 요약 | 계약까지 걸린 날 |
| 4. 월간 기록 | 월간 관리 리포트, 임차인용 관리비 내역서 | 열람률 |
| 5. 건물 현판 | 출입구의 관리 건물 표시와 점검 완료 스티커 | 현판 건물 수, 소개 계약 비중 |

- **거리 노출:** 홍대권 대상 건물 1,593동 중 966동(61%)이 도로 묶음 5개(동교로, 와우산로, 양화로, 잔다리로, 월드컵북로)에 있습니다. 현판이 곧 거리 광고가 됩니다.
- **현판 규정:** 현판과 스티커가 옥외광고물 신고 대상인지는 확인하지 못했습니다. 달기 전에 마포구청에 확인합니다.
- **연락 방식:** 우편과 방문만 씁니다. 문자·이메일 광고는 사전 동의가 필요합니다(정보통신망법 제50조).
- **시각:**
  - 색은 지금 웹의 청색(#1f5c8b)을 유지합니다.
  - 상징은 건물 윤곽 안에 확인 표시를 넣은 '점검 도장'입니다.
  - 로고와 서식은 이름을 정한 뒤에 만듭니다.
- **인수 업체:** 인수 후 12개월은 '기존 상호 + 빌딩모아'를 함께 씁니다.

## 결정이 필요한 것

1. 약속 문장 "관리사무소 없는 건물의 관리사무소"를 채택할지.
2. 이름을 1안 '빌딩모아'로 할지, 2안 '빌딩지기'로 할지(상표 조회 뒤 확정).
3. 상품 이름에서 '법정관리'를 빼고 '빌딩모아 점검·종합·공사'로 바꿀지.
4. '업체에서 수수료를 받지 않는다'를 브랜드 원칙으로 삼을지.
5. 웹 첫 화면 문구를 바꿀지.
