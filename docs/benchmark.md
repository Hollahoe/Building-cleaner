# 벤치마킹과 청사진 요약

경쟁사 17곳을 조사해 가져올 것, 피할 것, 차별화, 단계별 로드맵, 액션 아이템 200개를 정리했습니다.
전체 분석(회사별 상세, 비교표, 그림, 출처)은 Claude 문서 **[빌딩모아관리 벤치마킹과 청사진](https://claude.ai/artifact/8e4K4bqGK9xoJc86WzE1Rw)** 에 있고,
이 파일은 레포에서 바로 볼 수 있는 요약입니다. 액션 아이템 전체는 [`ops/action-items.csv`](../ops/action-items.csv)(노션 가져오기용)에 있습니다.

> **조사 한계.** 작성 환경에서 대부분의 회사 사이트와 기사 원문을 직접 열 수 없어서, 검색 결과에 인용된 내용을 기준으로 썼습니다.
> 회사가 스스로 발표한 숫자는 "회사 주장"입니다. 투자·영업 자료에 쓰기 전에 원문을 다시 확인하세요.

## 조사 대상 (17곳)

| 조사팀 | 회사 | 보는 이유 |
|---|---|---|
| A. 국내 소형 건물 관리 플랫폼 | 빌라온, 둥지(컨텍터스), 빌딩케어(디원더) | 같은 고객을 두고 직접 부딪히는 곳 |
| B. 국내 임대·운영 대행 | 자리톡, 패스트파이브 매니지드 바이, 알스퀘어, 빌즈, 홈매니저 | 건물주가 지금 돈을 내는 대안 |
| C. 해외 유지보수 마켓플레이스 | Plentific, Latchel, Fixflo | 업체 네트워크를 플랫폼으로 키운 선례 |
| D. 해외 공동구매 네트워크 | Landlords Buying Group Canada, Community Buying Group, RealPage eSupply | 우리와 가장 가까운 수익 구조 |
| E. 국내 구매·매칭 장치 | K-apt 전자입찰(선정지침), 숨고, 아파트너 | 업체 선정·견적 절차를 빌려올 곳 |

## 결론

- **비어 있는 자리:** "동네 건물을 묶어 시설 용역을 공동구매하고, 운영까지 대신 하는" 곳은 17곳 중 없었습니다.
  국내는 건물 하나 단위의 대행이나 소프트웨어이고, 해외 공동구매 조직은 물품 중심에 대행이 없습니다.
- **가장 가까운 추격자:** 빌라온(13종 묶음)과 둥지(거점 밀도). 기능은 따라 할 수 있으니 한 구의 밀도와 업체 관계를 먼저 잡습니다.

## 차별화 다섯 가지

| 차별화 | 무엇을 하나 |
|---|---|
| 1. 묶음 구매 + 대행 | 동네 건물을 묶어 업체를 고르고, 점검·민원·보고까지 대신 함 |
| 2. 공개 입찰 | 묶음 사양서 공고, 견적 2곳 이상, 미리 공개한 평가표, 결과 공개 (K-apt 선정지침의 절차를 빌림) |
| 3. 공개 수수료 | 우리 보수와 업체 대가를 비율·기준·지급 시기까지 약관에 숫자로 |
| 4. 적정가 + 품질 | 최저가 낙찰을 하지 않고 품질 배점·점검 기록·KPI 리포트로 관리 |
| 5. 동네 밀도 + 공개 수요 | 한 구에 집중, 동네·항목별 수요를 공개하고 기준에 닿으면 입찰 |

**하지 않는 것:** 건물주의 돈을 맡지 않고, 보험·중개·법률·세무를 팔지 않고, 광고를 붙이지 않고, 업체 계약은 건물주 명의로 직접 맺습니다.

## 경쟁사에서 가져올 것 (주요)

| 가져올 것 | 출처 |
|---|---|
| 검증 업체 풀과 표준 조건을 먼저 확정하고, 건물주는 직접 계약(지명 또는 3곳 미니 경쟁) | Plentific Open Framework |
| 항목별 고정 단가표 공개 | Fixflo |
| "지금 업체가 더 싸면 그대로 두세요" 보장 | RealPage eSupply |
| 첫 화면에 가격 원칙 한 줄 + "위약금 없음·절감 없으면 0원" | 빌라온, Latchel |
| "주소 한 줄 → 1분 비용 진단" | 빌즈, 자리톡 |
| 무료 법정 점검 캘린더와 알림으로 진입 | 자리톡, Fixflo |
| 수요 게시판을 업체 유치 무기로 ("○○동 승강기 묶음 N건 대기") | 알스퀘어 |
| 채널별 추천 코드, 파트너 이름을 단 화이트라벨 | Community Buying Group |

나머지(모두 20개)와 피할 것 7개는 Claude 문서의 '벤치마킹할 요소'에 있습니다.

## 단계와 관문

| 단계 | 목표 | 다음으로 넘어가는 관문 |
|---|---|---|
| 0–3개월 · 검증과 파일럿 | 파일럿 3곳 | 돈 내는 건물 3곳(같은 구), 고지서로 증명한 절감 1건, 같은 업무 월 10회 반복, 쐐기 확정 ([전략 6번](strategy.md#6-3단계-로드맵과-전환-기준)) |
| 4–6개월 · 한 구 밀도 | 관리 건물 10곳 | 한 구에서 10곳, 반복 업무·절감 증빙·밀도 판정, 운영자 1명당 건물 수 측정 |
| 7–12개월 · 구 확장과 플랫폼 v1 | 30곳 · 2–3개 구 | 관리 건물 30곳(70% 이상 한 구) `[가설]`, 같은 견적 요청 10번 반복, 업체가 먼저 참여 요청 ([전략 6번](strategy.md#6-3단계-로드맵과-전환-기준)) |
| 2년차 · 서울 확장과 구매 네트워크 | 150곳 · 5개 구 | 구 오픈 플레이북 v1, 시리즈 A 준비 지표(반복 매출·이탈·1인당 건물) |
| 3년차 이후 · 300억 회사 | 1,000곳 → 2,500–4,200곳 `[가설]` | |

관문을 못 넘으면 [중단·방향 전환 기준](strategy.md#7-중단방향-전환-기준)대로 접거나 방향을 바꿉니다.

## 300억까지의 숫자 `[가설]`

기업가치 300억 원 회사는, 아래 가정대로라면 서울 꼬마빌딩 약 2,500–4,200곳의 운영비가 우리를 거쳐 계약되는 회사입니다.
배수와 단가는 모두 가정이고 시장 근거가 있는 숫자가 아닙니다.

| 시나리오 | 건물당 월 매출 | 연매출 60억 원(가치 ÷ 5배)에 필요한 건물 | 연매출 100억 원(가치 ÷ 3배)에 필요한 건물 |
|---|---|---|---|
| A. 기본료만 | 15만 원 | 3,334곳 | 5,556곳 |
| B. 기본료 + 공개 수수료(거래액 월 130만 원 × 4%) | 20만 원 | 2,500곳 | 4,167곳 |
| C. B + 업체 쪽 매출 | 30만 원 | 1,667곳 | 2,778곳 |

- B 기준 2,500–4,200곳은 서울 25개 구에서 구당 약 100–170곳입니다. 한 구에서 100곳을 만드는 방법을 먼저 증명하고 복제합니다.
- 운영자 1명이 60곳을 맡으면 운영 인력은 42–70명입니다.
- 서울의 대상 건물 수는 아직 모릅니다. 건축물대장으로 직접 세어야 합니다.
