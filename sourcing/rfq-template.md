# 업체 견적 요청서

> 항목별로 업체 2곳 이상에 보냅니다. 받은 견적은 [`vendors.csv`](vendors.csv)에 기록하고, 엑셀 `견적비교` 시트에 입력합니다.
> **가장 중요한 질문:** "건물 1채 / 3채 / 5채 / 10채를 묶으면 단가가 얼마까지 되나요?" 이 차이가 공동구매의 근거입니다.

## 공통 문구 (카톡·이메일)

```
안녕하세요, {이름}입니다.
소규모 건물 여러 곳의 관리를 맡아 업체를 비교하고 있습니다.
아래 조건으로 견적 부탁드립니다. 건물 수에 따른 단가 차이도 함께 알려주시면 감사하겠습니다.

1) 건물 1채 기준 월 금액
2) 같은 조건의 건물 3채 / 5채 / 10채를 함께 계약할 경우 1채당 월 금액
3) 포함 범위와 제외 범위
4) 계약 기간, 해지 조건
5) 업종 등록·신고증 사본

계약은 각 건물주님이 직접 하시게 됩니다.
{연락처}
```

## 항목별로 꼭 적어 보낼 조건

같은 조건으로 받아야 견적끼리 비교할 수 있습니다.

### 청소 용역
- 건물 유형, 층수, 공용부 면적(계단, 복도, 화장실 수)
- 주기(주 __회), 1회 작업 시간
- 범위: 계단·복도 / 공용 화장실 / 분리수거장 / 외부(주차장, 건물 앞) / 유리창(분기·반기)
- 소모품(화장지, 세제, 쓰레기봉투) 포함 여부
- 품질 확인 방법(작업 후 사진 등)
- **확인:** 건물위생관리업 신고증

### 승강기 유지보수
- 대수, 제조사, 설치 연도, 용도(승객용·화물용), 정지 층수
- 월 자체점검 대행 포함 여부, 승강기안전정보망 기록 입력 대행 여부
- 부품 교체 비용 포함 범위(소모품만 / 주요 부품 포함)
- 고장 출동 시간(평일·야간·주말)
- 정기검사 입회 포함 여부
- 설치 15년이 넘은 승강기라면 정밀안전검사 대응 방법([법정 점검 캘린더](../ops/compliance-calendar.md) 참고)
- **확인:** 승강기 유지관리업 등록증

### 소방 점검
- 건물 용도, 연면적, 층수, 사용승인일(점검 시기가 사용승인일이 속한 달을 기준으로 정해짐)
- 점검 종류(작동점검 / 종합점검) — 건물이 어디에 해당하는지 업체 의견도 함께 받기
- 관할 소방서 결과 보고 대행 포함 여부
- 지적사항 보수 공사 견적 방식(별도 견적인지)
- **확인:** 소방시설관리업 등록증 또는 점검자 자격

### 건물 종합보험 (견적 요청하지 않음)
운영자는 견적을 받거나 상품을 비교하지 않습니다([법률 체크리스트 1번](../docs/legal-checklist.md#1-보험-보험업법-제83조)).
건물주 동의를 받아 **현재 증권만** 정리합니다: 보험사, 상품명, 보장 항목, 연 보험료, 만기일.

### 세무·법률 (견적 요청하지 않음)
운영자는 견적이나 알선을 하지 않습니다([법률 체크리스트 2–3번](../docs/legal-checklist.md#2-세무-세무사법-제2조의2)).

## 견적 받은 뒤 확인

- [ ] 포함·제외 범위가 기존 업체와 같은가? 다르면 `견적비교` 시트 메모에 적기
- [ ] 묶음 할인 조건이 "같은 날 계약"인지, "같은 동네"인지, "합산 대수"인지
- [ ] 견적 유효 기간
- [ ] 등록·신고증 사본을 받았는가
