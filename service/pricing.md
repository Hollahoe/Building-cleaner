# 가격 모델

> 이 문서의 금액·비율은 모두 `[가설]`입니다. Week 3–4에 받은 실제 견적으로 [`tools/savings-calculator.xlsx`](../tools/savings-calculator.xlsx)의 `절감수수료` 시트를 채운 뒤 확정하세요.

## 두 가지 모델

| | A) 월 구독 | B) 절감분 성과 보수 |
|---|---|---|
| 구조 | 월 19.9만–29.9만 원 `[가설]` + 공동구매 관련 보수 | 관리비 절감액의 30% `[가설]` |
| 건물주 입장 | 절감이 안 돼도 매달 나가는 고정비 | **절감이 없으면 0원** |
| 운영자 입장 | 수입이 예측 가능 | 절감 실적에 따라 수입이 달라짐 |
| 설득 난이도 | 어려움(처음 보는 사람에게 매달 돈 내기) | 쉬움 |
| 언제 쓰나 | 케이스 스터디가 쌓인 뒤(2단계) | **1단계 파일럿** |

**1단계는 B로 시작합니다.** 핵심 멘트: "절감 못 하면 돈 안 받겠습니다."

## 모델 B의 계산식

```
월 보수 = (기준 월비용 − 변경 후 월비용) × 수수료율
          단, 결과가 0보다 작으면 0
```

### 분쟁을 막으려면 계약서에 숫자로 적을 것

| 항목 | 정해야 할 것 | 권장 출발점 (결정 필요) |
|---|---|---|
| **기준 월비용** | 무엇을 기준으로 볼지 | 계약 직전 3개월 고지서·이체 내역의 평균. 항목별로 따로 적음 |
| **비교 범위** | 같은 서비스끼리 비교하는지 | 청소 주기·범위, 승강기 부품 포함 범위 등 **서비스 범위가 같은 것끼리만** 비교. 범위가 줄어서 싸진 건 절감으로 치지 않음 |
| **수수료율** | 몇 % | 30% `[가설]` |
| **받는 기간** | 언제까지 받는지 | 절감이 시작된 달부터 12개월 또는 운영 계약 기간 중 짧은 쪽 |
| **업체 단가 인상** | 업체가 다음 해 단가를 올리면 | 인상분만큼 절감액이 줄어든 것으로 보고 다시 계산 |
| **정산** | 언제, 어떻게 | 매월 말 월간 보고서와 함께 청구, 건물주 계좌에서 운영자 사업자 계좌로 이체 |

### 예시 `[가설]`

조언에서 나온 예시: "혼자 하면 월 200만 원 나오는 걸 10명 묶으면 130만 원으로."

| | 금액 |
|---|---|
| 기준 월비용(건물 1개, 갈래 A 항목 합계) | 2,000,000원 |
| 변경 후 월비용 | 1,300,000원 |
| 월 절감액 | 700,000원 |
| 운영자 월 보수(30%) | 210,000원 |
| 건물주 실제 절감액 | 490,000원 |

이 숫자는 검증되지 않았습니다. 묶음 할인이 실제로 얼마나 되는지는 업체 견적(1채 / 3채 / 5채 / 10채)으로 확인해야 합니다.

## 업체에서 받는 돈에 대한 원칙

- **보험·세무·법률·중개 관련 업체로부터는 어떤 대가도 받지 않습니다.** → [법률 체크리스트](../docs/legal-checklist.md)
- 청소·승강기·소방 업체로부터 소개 수수료나 리베이트를 받는다면 **건물주에게 금액을 공개**합니다.
  건물주가 모르는 업체 수수료는 신뢰를 한 번에 무너뜨립니다. 1단계에서는 받지 않는 것을 권장합니다.

## 모델 A로 바꿀 시점

- 케이스 스터디 3건 이상
- 절감이 끝난 뒤(받는 기간이 지난 뒤)에도 건물주가 관리를 계속 맡기고 싶어 할 때
- 이때 B에서 A로 넘어가는 조건(예: 13개월째부터 월 구독)을 처음 계약서에 미리 적어두면 협상이 쉬워집니다.
