## 1. 멘토님께 후속 메시지

이미 보낸 메시지에 이어서 붙일 문구입니다(조언에서 제안한 문장 그대로).

```
대표님 말씀 듣고 생각해보니 앱만으로는 한계가 있는 게 맞더라고요.
앱은 소규모 건물주분들 모으는 진단 툴로 쓰고, 실제 수익은 공동구매형 건물관리로 가져가는 구조로 한 번 구체화해보고 싶습니다.
혹시 소규모 건물주분들 2-3분만 인터뷰 연결해주실 수 있을까요?
```

## 2. 인터뷰 섭외 (지인 소개)

```
안녕하세요, {소개자}님 소개로 연락드린 {이름}입니다.
소규모 건물 관리하시면서 어떤 점이 힘드신지 배우고 싶어서 연락드렸어요.
뭘 팔려는 건 아니고, 30분 정도 편하게 말씀 들을 수 있을까요?
말씀해주신 내용은 정리해서 리포트로 보내드리겠습니다.
{가능한 요일·시간 2–3개} 중에 편하신 때 알려주시면 찾아뵙거나 전화드릴게요.
```

## 3. 인터뷰 섭외 (카페·번영회)

```
안녕하세요, 소규모 건물 관리 문제를 공부하고 있는 {이름}입니다.
꼬마빌딩·상가주택·원룸 건물을 직접 관리하시는 건물주님께
관리하면서 제일 돈 아깝고 머리 아팠던 경험을 30분만 여쭙고 싶습니다.
영업 목적이 아니고, 들은 내용은 익명으로 정리해서 참여해주신 분들께 리포트로 공유드립니다.
관심 있으시면 쪽지 부탁드립니다.
```

## 4. 인터뷰 직후 감사 인사

```
{호칭}님, 오늘 귀한 시간 내주셔서 감사합니다.
특히 {인상 깊었던 이야기 한 가지} 말씀이 많이 와닿았습니다.
다른 건물주님들 말씀까지 모아서 {날짜}까지 정리해 보내드릴게요.
혹시 비슷한 고민을 하시는 건물주님이 계시면 소개 부탁드려도 될까요?
```

## 5. 인터뷰 결과 리포트 발송

```
{호칭}님, 약속드린 정리 내용 보내드립니다.
건물주님 {__}분께 여쭤본 결과, 가장 많이 나온 고민은
1) {1위}
2) {2위}
3) {3위}
였습니다. 자세한 내용은 첨부 파일에 정리했습니다.

이 중에 {1위 항목}은 제가 직접 업체 견적을 비교해드릴 수 있을 것 같아요.
절감이 안 되면 비용은 받지 않는 방식으로, 건물 몇 곳만 시범으로 해보려고 합니다.
관심 있으시면 편하게 말씀 주세요.
```

## 6. 파일럿 제안

```
{호칭}님, 말씀드렸던 시범 관리 내용 정리해서 보내드립니다.

- 제가 하는 일: {항목} 업체 견적 비교, 점검 일정 관리, 민원 접수·업체 연결, 월 1회 보고
- 업체 계약은 {호칭}님 명의로 직접 하십니다. 제가 중간에서 돈을 받거나 맡아두지 않습니다.
- 비용: 지금보다 줄어든 금액의 {30}%만 받습니다. 줄지 않으면 0원입니다.
- 시작하려면 최근 3개월 고지서와 지금 업체 계약서 사진만 보내주시면 됩니다.

먼저 무료로 건물 진단 리포트 1장 만들어드릴게요.
```

